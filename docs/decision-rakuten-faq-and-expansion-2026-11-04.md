FAQ 도메인에 대한 `curl`을 **1회** 시도했고 연결에 실패(`http=000`)해 더 시도하지 않았다(규정 본문 호스트는 이전 턴에서 이미 `403`/DNS 실패).
따라서 이 절의 FAQ 내용은 **전부 사용자 제공 요약**이며 독립적으로 검증하지 않았다. 정확한 표현·적용 범위(예: "일반적인" 캐시 기간이 상한인지 권장인지, 예외 API 목록)는 **UNKNOWN**이다.

### 1.2 제8조 4항과 FAQ ①의 적용 범위 차이

| | 제8조 4항 (조항 요약, 원문 미열람) | FAQ ① (요약) |
|---|---|---|
| 규율 대상 | API를 쓰는 애플리케이션 부분에서 **라쿠텐 외 사이트로의 링크 제공** | **타사 웹서비스에서 얻은 상품**을 라쿠텐 상품과 **함께 놓는 것(병기)** |
| 성격 | 이동 경로(링크) | 데이터 표시 |
| 조건 | 제한 | **출처 표시를 조건으로 가능** |
| 공백 | — | **병기 허용이 해당 상품의 구매 링크 제공까지 포함하는지는 요약에 없음 (UNKNOWN)** |

가격비교 서비스에서 병기(A)와 구매 링크(B)는 분리되지 않는 기능이지만, **규정 상으로는 별개 항목이다.** FAQ ①이 A를 풀어도 B가 풀렸다고 볼 근거는 없다.

### 1.3 8개 항목별 판정

판정 라벨: **CONFIRMED**(원문으로 확인) / **CONDITIONAL**(조건부로 허용된다는 *요약*) / **UNKNOWN** / **RESTRICTED**(제한이 있다는 *요약*).
원문을 한 건도 읽지 못했으므로 **CONFIRMED는 0건**이다. "운영 가정"은 확인 전 Tripprice가 취할 보수적 행동이며 법적 결론이 아니다.

| 항목 | 근거 | 판정 | 조건 / 운영 가정 | Tripprice 현재 코드 |
|---|---|---|---|---|
| **A** 다른 쇼핑몰 상품과 함께 표시 | FAQ ① | **CONDITIONAL** | 출처 표시. 표기 방식·위치는 UNKNOWN | 판매처명 라벨("라쿠텐")만 표시. 별도 출처 문구 없음 |
| **B** 다른 쇼핑몰 **구매 링크** 제공 | 제8조 4항 (FAQ ①은 링크 언급 없음) | **RESTRICTED** (조항 요약 기준) | FAQ ①이 이를 완화하는지 **UNKNOWN**. 해소 전엔 라쿠텐 데이터가 있는 화면에 타 몰 링크를 *추가로 늘리지 않음* | 리스팅별 `sourceUrl` 링크 노출 중 |
| **C** 다른 쇼핑몰 **제휴 수익화** | FAQ ④ + 제10조 1항 4·5호 | **RESTRICTED** | "일부 API는 다른 제휴 허용"의 **대상 API 목록이 UNKNOWN**. Ichiba Item/Product Search가 포함되는지 모름 | 코드에 제휴 링크 구현 **없음** (현재 위반 행위 없음) |
| **D** Google AdSense 광고 수익화 | FAQ는 *제휴 서비스*를 다룸. 광고 네트워크 언급 없음. 제10조 1항 4호(요약: 라쿠텐 제휴 외 수익화 제한) | **UNKNOWN** | C와 별개. 허용을 추정하지 않음 | 코드에 AdSense **없음** |
| **E** 가격 데이터 **일시 캐시** | FAQ ② | **CONDITIONAL** | 가격·판매가능 정보 일반 **24시간**, 기타 정보 **3개월**. "일반적"의 구속력 UNKNOWN | 현재가는 갱신될 때까지 DB에 유지 (아래 §2) |
| **F** 가격 **이력 장기 저장** | FAQ ②는 *캐시 기간*만 언급. 이력 보관 예외 언급 없음. 제10조 1항 9호 | **UNKNOWN** | 24시간 기준과 **충돌 가능성이 높아** 확인 전까지 *확대 금지*로 취급. **기존 이력은 삭제하지 않음** | `price_history` 무기한 보관 (아래 §2) |
| **G** 가격의 **공개 재표시** | FAQ ② | **CONDITIONAL** | 표시 시 **최소 주 1회** 새로 조회. 매시간 미만 갱신이면 **갱신 시각 + 안내 문구** 표시 의무 | 6시간 주기 → 시각·안내 의무 대상. 시각은 표시, 문구 규격은 UNKNOWN |
| **H** **제품 식별** 목적 사용 | FAQ에 명시 없음. 기타 정보 3개월 캐시 기준이 적용될 수 있음 | **UNKNOWN** | 허용을 추정하지 않음 | 모델번호(`productNo`)는 발굴 전용, 라이브 미검증 |

**서로 독립이다**: A·E·G가 CONDITIONAL이어도 B·C·F는 열리지 않았다.
**사업 모델과의 충돌 가능성**: ① B(구매 링크)와 C(제휴 수익화)는 가격비교의 존재 이유와 같은 축이라 가장 크다.
② F(이력)는 이미 운영 중인 기능과 맞닿는다. ③ A·E·G는 조건(출처·갱신·안내)을 지키면 설계 변경 없이 맞출 수 있는 영역으로 보이나 규격은 UNKNOWN이다.

### 1.4 라쿠텐에 확인할 사실 질문 (발송하지 않음)

FAQ ③에 따라 "Tripprice가 허용되는가"는 묻지 않는다. 라쿠텐이 *공개 규정에 대해 설명할 수 있는 사실*만 묻는다.
(회신이 오지 않을 가능성이 높다. 원문 열람이 가능해지면 이 질문 다수는 불필요해진다.)

**日本語**
1. 他社ウェブサービスの商品を併置する際に必要な「出典表示」の具体的な表記方法（文言・表示位置）を教えてください。
2. 他の提携（アフィリエイト）プログラムの利用が認められているAPIの一覧を教えてください。市場商品検索API、商品価格ナビ製品検索APIは含まれますか。
3. 価格・販売可否情報の「一般的なキャッシュ期間は24時間」という記載は、保存期間の上限を意味しますか、それとも目安ですか。また、価格の履歴データにも同じ考え方が適用されますか。

**한국어**
1. 타사 웹서비스의 상품을 병기할 때 필요한 "출처 표시"의 구체적 표기 방식(문구·표시 위치)을 알려 주십시오.
2. 다른 제휴(어필리에이트) 프로그램 이용이 허용되는 API 목록을 알려 주십시오. 이치바 상품 검색 API, 상품가격내비 제품 검색 API가 포함됩니까?
3. 가격·판매 가능 정보의 "일반적인 캐시 기간은 24시간"이라는 기재는 보관 기간의 상한입니까, 권장입니까? 가격 이력 데이터에도 같은 기준이 적용됩니까?

### 최소 수정 방안 (이번에 적용하지 않음)

새로 *명백히 재현된 안전성 결함*은 없다. 5번은 재현됐지만 **운영 설정(6번)에 따라 결함 여부가 갈리고**,
수정은 공개 화면의 동작을 바꾸므로(갱신이 안 도는 환경에서는 비교 화면이 비게 됨) 코드 변경을 하지 않았다.

| 방안 | 유형 | 비고 |
|---|---|---|
| P1. 스케줄 작업에 `stale-sweep` 추가 | **운영 설정(배포)** | 가장 작은 변경. 기존 `staleAfterHours`(24h)를 그대로 사용 |
| P2. `Offer`에 `lastSuccessAt`을 싣고 나이 초과 시 `stale`로 비교 제외 | 작은 코드 + 테스트 | P1이 없을 때만 필요. 사용자 결정 후 |
| P3. 이력(F)은 **삭제하지 않고** 신규 확대만 보류 | 정책 | 스키마 변경 불필요 |
| P4. 출처·갱신 안내 문구 | 문구 변경 | **원문 규격 확인 후** |

## 3. 공급처 우선순위: Yahoo Shopping vs 11번가

기존 조사(11-03)를 재사용하고 이번에 확인된 것만 더한다. 등급: B=공식 발췌, C=2차, U=UNKNOWN.

| 항목 | Yahoo Shopping v3 | 11번가 Open API |
|---|---|---|
| 1. 한국 거주 개인 가입 | **U.** Yahoo! JAPAN ID가 관문. 공식 헬프 발췌: 해외 번호 SMS 인증 불가(B, 11-03). 이번 검색: 해외 번호 정책 확인 불가 | **B.** 셀러 전환 불필요, self-service 키 발급 (11-03). 인증키 180일 유효기간 보도(C, 판매자 API 기준인지 U) |
| 2. 판매처별 상품가격 | B. 상점 단위 상품, JAN 검색. 응답 필드명 **미확인** | B. 판매자·가격 포함 (11-03). **재확인 불가** |
| 3. 상업적 가격비교 | **U.** 기본 비상용, 법인 상업은 문의 (B, 11-03). 규정은 "ガイドライン"과 API별 "利用のルール" 페이지에 있음(이번 확인), 본문 미열람 | **U.** 이번 검색 0건 |
| 4. 저장·재표시 | **U** | **U** |
| 5. 식별자 | JAN 검색(B). 모델번호 필드 U | 상품코드만, GTIN 없음(B) |
| 6. 갱신·한도 | 분당 30회(B, 11-03), 문서상 1쿼리/초(이번, B) | pageSize 최대 200(B). 호출 한도 **U** |
| 7. 필요한 사용자 행동 | 도메인 허용 → ガイドライン·利用のルール 열람(계정 불필요) → JP ID 개설 시도 → 상업이용 문의(일본어) | 도메인 허용 → 서비스 등록·키 발급(무료) → **약관 원문 저장·전달** → 1:1 문의 (11-03 문안) |

### 추천: **11번가를 먼저 접근**한다 (채택 가능 여부는 둘 다 UNKNOWN)

근거는 *도입 확정*이 아니라 *접근 순서*다.
1. **접근 장벽의 비대칭**: 11번가는 한국 거주 개인에게 공식 발췌상 장벽이 낮고(셀러 불필요·무료), Yahoo는 첫 단계(JP ID, 해외 번호)가 이진 UNKNOWN이다.
2. **막힌 지점을 정확히 메운다**: 병목은 한국 다판매처 + 쿠팡 재고 미상(이전 보고)이며 11번가 외엔 후보가 없다. 일본 판매처 가격은 라쿠텐이 (조건부로) 이미 있다.
3. **결정력**: 사용자의 5~30분 무료 행동(약관 열람)으로 채택/기각이 거의 갈린다.

**우선순위가 뒤집히는 조건**: 라쿠텐의 B·C가 해소되지 않아 일본 가격을 라쿠텐에 둘 수 없게 되면 **Yahoo가 일본 측 1순위**가 된다. 그래서 Yahoo의 *계정이 필요 없는 단계*(규정 열람)는 지금 병행한다.
**11번가가 거절되면** 한국은 쿠팡 단독이며 "한국 내 복수 판매처 비교"는 성립하지 않는다 — 이 경우 판매자 공식 피드가 유일한 경로다.

## 4. 실제 비교 가능 상품 수 확대

### 4.1 지금 늘지 않는 이유 — 네 지표 (합성 제외, API 검색 결과 수 제외)

| 지표 | 값 | 비고 |
|---|---|---|
| ① 제품 후보 수 | **448** (저장소 실제 상품 정체성) | 이 중 모델번호 보유 **7**. 라이브 발굴(Rakuten Product/쿠팡) 수는 **미측정** |
| ② 판매처별 실제 가격 확보 수 | **미측정 (라이브 0건)** | 과거 기록뿐: 승인 리스팅 4건(2026-08-15 가격, 현재가 아님), CSV 3-way 가격 확인 2건(수동·과거). DB 보유 건수는 운영 DB 미조회 |
| ③ 한일 동일 상품 매칭 성공 수 | **확인된 수 0** | `approved-mappings.json`에 양쪽이 모두 승인된 상품 0/4. CSV는 한일 URL이 모두 있는 상품 7/10이나 수기 조사이며 승인 매핑이 아님. DB 미조회 |
| ④ 공개 이용 권한 확인된 비교 가능 상품 수 | **0** | 원문으로 확인된 공급처 0곳 |

따라서 부족한 것은 코드나 후보 수가 아니라 **②(실측 가격)과 ④(권한)** 이다. ①은 이미 448개(정체성)이지만 모델번호가 있는 것이 1.6%뿐이어서 ③으로 이어지지 못한다.
합성 실험(3,410 "비교 가능 묶음")은 지표에 포함하지 않으며, 그것은 *가격 후보*였고 재고 확인 묶음은 0이었다.

### 4.2 100 / 500 / 1,000 개 — 검증해야 할 조건 (달성 추정 아님)

"비교 가능 상품" = 한국·일본 **판매처 단위** 가격 + 구매 URL + 신선도 통과 + 사람이 승인한 최초 매핑 + **사용 공급처의 권한 확인**.

공통 관문 G1~G6 (어느 규모든 필요):
G1 권한 근거 확보 · G2 신선도 정책(표시 가격 최대 나이, stale 차단 작동, 시각·안내) · G3 판매처 단위(`seller_listing`) · G4 모델번호 근거 + 첫 매핑 사람 승인 · G5 출처 표시 · G6 호출 예산 실측.

| 규모 | 추가로 검증할 조건 | 현재 |
|---|---|---|
| **100** | 샘플 26개 라이브 프로브로 **쌍 확보율**(한·일 판매처 단위 가격이 동시에 나오는 비율) 측정. 사용 가능한 일본 측 공급처의 권한(라쿠텐 B·C 해소 *또는* 라쿠텐과 무관한 일본 공급처) | 쌍 확보율 미측정, 권한 0 |
| **500** | 모델번호 공급 경로 확정(`productNo` 채움률 *또는* 피드 `model`). 모델번호 보유 카테고리 선별. 사람 승인 부담 산정(자동 승인 레인은 `review.json` 없이는 임계치 산출 BLOCKED) | 모델번호 1.6%, `productNo` 미검증 |
| **1,000** | 위 + 카테고리 2개 이상 + **갱신 호출 예산**: 리스팅 ≥2,000(상품당 한국 1 + 일본 1 이상). 쿠팡이 시간당 10회(C, 미측정)라면 일일 갱신 상한 240건, **주 1회 갱신 상한 1,680건** → 1,000 리스팅은 주 1회로만 가능하고 표시 나이가 최대 7일이 되어 시각·안내 의무 대상. 한도가 분당 50이면 해소 | 한도 **미측정** |

선결 문제: 라쿠텐 B(구매 링크)가 RESTRICTED로 확정되면 **라쿠텐이 낀 쌍은 공개 화면에 올릴 수 없다.** 그 경우 100도 라쿠텐과 무관한 일본 공급처(Yahoo·피드)가 필요하다.
